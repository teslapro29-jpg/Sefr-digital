CEFR Digital Speaking — Android Studio loyihasi

Bu loyiha yuklangan HTML mock imtihonini Android WebView ichida ishga tushiradi.
Mikrofon uchun Android RECORD_AUDIO ruxsati so'raladi. HTML fayl AndroidX WebViewAssetLoader
orqali HTTPS ko'rinishidagi xavfsiz appassets origin'da ochiladi.

APK yig'ish:
1. Kompyuterga Android Studio o'rnating.
2. Ushbu ZIP faylni oching.
3. Android Studio -> Open -> CEFR_Digital_Android_Project papkasini tanlang.
4. Gradle sync tugashini kuting.
5. Build -> Build Bundle(s) / APK(s) -> Build APK(s).
6. app/build/outputs/apk/debug/app-debug.apk faylini telefonga o'tkazing va o'rnating.

Eslatma:
- Birinchi ishga tushganda mikrofon ruxsatini bering.
- Ilova ichidagi savollar va imtihon materiallari asl HTML fayldan olingan.
- ZIP eksporti WebView'da qurilmaga yuklash ruxsati va brauzer xatti-harakatlariga bog'liq;
  yakuniy APK'da eksport tugmasini alohida sinab ko'rish kerak.
- Bu ZIP APK emas, Android Studio'da APK yaratish uchun manba loyiha.
